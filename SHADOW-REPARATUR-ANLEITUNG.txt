GITHUB ANLEITUNG:
1. Ein NEUES, leeres GitHub-Repository erstellen, z.B. shadow-client-fixed.
2. Diese ZIP entpacken. Den INHALT des entpackten Ordners ins neue Repository hochladen.
   Wichtig: src-tauri, src, scripts, package.json muessen DIREKT im Repository liegen.
3. GitHub > Actions > Shadow Client Windows > Run workflow.
4. Bei Erfolg unter Actions > letzter Lauf > Artifacts den Windows-Installer herunterladen.
